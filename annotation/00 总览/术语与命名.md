# 术语与命名

同一件事在不同层有不同叫法。下面按“代码里实际使用的名字”给出统一说法，避免把 `record` 和 `dto` 混着用。

## 核心说法

| 术语 | 指什么 | 在哪 |
| --- | --- | --- |
| `S` | 前端唯一聚合响应式状态，`reactive` 对象，面板直接读写 | `store/project.js` |
| `dto` | 壳侧序列化契约对象，camelCase，只为跨 IPC 存在 | `src-tauri/src/dto.rs` |
| `record` | 一条内容记录的前端投影，有 `id/type/name/fields` | `S.project.records` |
| `materialize` | 把壳下发的 DTO 装配进 `S`，如 `materializeSummary` | `store/project.js` |
| `draft` | 字段编辑草稿，尚未提交；切换记录即丢弃 | `shared/fieldDrafts.js` |
| `selectedId` | 当前选中记录的 id，选择链路的单一信号 | `S.selectedId` |
| `workspace` | 主区当前页签（assets/units/canvas/cosmos/tech/script） | `S.ui.workspace` |
| `issues` | 校验结果列表，`level` 只有 error 与 warn | `S.issues` |
| `vanilla` | 游戏原版自带内容，不是本模组创建的记录 | `schema.js` 与 `vanilla-content.json` |

## 2026-11-26 增补：类名与关窗相关说法

| 术语 | 指什么 | 在哪 |
| --- | --- | --- |
| `script class`（脚本推断类） | 内容 JSON 没写 `type`，类由 `scripts/**/*.js` 的 `extend(<Class>, '<名>')` 静态扫出来；不执行脚本 | `mm-io/src/script_scan.rs` |
| `declared` / `script` / `default`（`classSource`） | 有效类的三级来源：内容里声明的 `type` > 脚本推断 > 类型默认类。DTO 逐字下发这三个拼写 | `mm-app/src/class_resolution.rs`、`dto.rs` 的 `classSource` |
| 有效类（`className`） | 游戏实际会用来加载该记录的类；**视图口径**，不写回磁盘上的 `type` | `RecordDto.className` / `RecordSchemaDto.className` |
| `window-close-requested` | 壳拦下原生 X/Alt+F4 后广播的空载荷事件；关窗守卫的入口 | `bridge::EVENT_WINDOW_CLOSE_REQUESTED` |
| `hold` | 前端收到关窗事件后立即调 `window_close_hold`，摘除本代 3s 兜底计时但保留请求；对话框因此有无限决策时间 | `close_guard::CloseGuard::hold` |
| `closeConfirm` | dirty 时的关窗对话框（保存并关闭 / 放弃并关闭 / 取消），不是 `S.ui.closed` 遮罩 | `home.vue`、`store/project.js` |
| `showSprites` | 缩略图总开关；关掉后 `spriteUrl()` 恒为空，列表回退色块 | `S.ui.showSprites` |

> 2026-11-26 更正：本篇原文的 `workspace` 取值缺 `units`（单位构建工作区已是独立页签，见 `UnitsPane.vue`）。

## 容易混的三组

- **canvas / board**：`canvas` 指方块构建这个工作区及其交互；`board` 指数据结构里的一块画板，一个项目可以有多块。
- **cosmos**：星球战役工作区，包含 planet 与 sector 两类记录，归属由 `sectorPlanet()` 决定。
- **tech**：科技研究工作区，`research` 字段是唯一数据源，树只是它的一种渲染。

> [!warning] 不要造同义词
> 新增字段名沿用上表：状态一律进 `S`，跨 IPC 一律叫 `dto`，界面上说“记录”的东西在代码里就是 `record`。同义新词会让分层扫描与 review 都失效。

## 命名约定

- 组件 `Ar` 前缀表示 Argon 控件；面板以 `Pane` 结尾；页面只有 `Home`。
- CSS 类名 `frame-*`、`vector-*` 来自设计稿坐标，不要重命名；新增交互样式另起语义类。
  2026-11-26 更正：z1 重做样式层后，`frame-*` 一类设计稿类名已基本被语义类（`titlebar` / `toolbar` / `statusbar` / `.field-row`）取代，两者不要混用。
- 事件名用小写连字符，命令名用下划线，参数跨 IPC 自动转 camelCase。
