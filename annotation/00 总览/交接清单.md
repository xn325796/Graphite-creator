# 交接清单

> **2026-11-26 就地更正**：z1 重做了壳与样式层，本篇原文里的「关窗只置遮罩」「七个菜单」「`cargo test` 只要求全绿」
> 都已不成立。现状：关窗走 `closeConfirm` 对话框 + `window_confirm_close`；菜单 8 个（多 `run`）；
> 测试基线 **228 / 0**、clippy **0/0**。原文条目保留在下方，新增/改写的条目以「2026-11-26」标注。
> 依据：`src/views/home.vue`、`src/lib/actions.js`、`cargo test --workspace` 与 `cargo clippy --workspace --all-targets` 实测。

接手或移交 GraphiteCreator 时，按下面四组逐项过一遍。每一项都能在仓库里当场验证，不依赖口头说明。

> [!tip] 使用方式
> 先跑“环境与构建”组，再跑功能组；任意一项失败就停在这一组，不要继续往下看，否则后面的结论不可信。

## 一、环境与构建

- [ ] `npm install` 无报错，依赖里没有 `pinia`、`vue-router`、`vitest`、`@tauri-apps/plugin-*`。
- [ ] `npm run dev` 起默认 1200×650 窗口；缩放到 960×600 与 1600×900 均无横向滚动条，控制台无报错。
- [ ] `npm run build` 通过，`dist/` 正常生成。
- [ ] `npm run tauri dev` 能拉起桌面窗口，关闭窗口不残留进程。
- [ ] `cargo test --workspace`（仓库根）**228 通过 / 0 失败**；`cargo clippy --workspace --all-targets` 零诊断（2026-11-26 实测）。不要用 `--manifest-path src-tauri/Cargo.toml`：只编壳会漏掉 9 个领域 crate（口径见 [[构建与验证]]）。
- [ ] 2026-11-26：`cargo fmt --all -- --check` **当前不干净**（`mm-app/src/card_geometry.rs`、`cosmos.rs` 等有长行 diff），不要把它当准入条件；新代码按周边风格手写，新增文件可用 `rustfmt --check` 单验。

## 二、主壳

- [ ] 六个页签可点击且高亮跟随 `S.ui.workspace`，script 页呈禁用灰；Ctrl+1…Ctrl+5 与菜单「视图」里的页签项一致。
- [ ] assets 与 units 都是「列表 + 检查器」两栏，中间的分隔条可拖动调宽、双击复位（宽度存 localStorage）。
- [ ] cosmos/tech/canvas 首次进入即有内容。
- [ ] 修改字段后状态栏出现未保存标记，120s 内自动保存并显示时间。
- [ ] 日志抽屉可开合、可复制/清空，条目不超 500 条且时间戳正常。
- [ ] Ctrl+K（或 Ctrl+Shift+P）打开命令面板；F1 打开快捷键帮助停靠层。
- [ ] 视图菜单可切深色/浅色/跟随系统，切换后 `<html data-theme>` 变化且无需刷新。

## 三、顶栏与快捷键

- [ ] 八个菜单全部可展开，禁用态与 `S.project`、撤销/重做栈一致。
- [ ] Ctrl+S 只触发一次保存 toast；Ctrl+Z/Y 后选择不丢、字段草稿已清空、导入过的缩略图已作废重拉。
- [ ] 在输入框里按 Ctrl+Z 走浏览器原生撤销，不会触发全局撤销（`home.vue` 的 `inField` 守卫）。
- [ ] F5 校验后 E/W 计数与日志同步变化，F6 能安装并启动。
- [ ] 切到 English 后菜单、工具栏、命令面板、tooltip 文案全部同步。
- [ ] 搜索框 Ctrl+F 聚焦、回车执行。
- [ ] 网格开关切到关时画布点阵消失（`CanvasPane` 的 `.cv-canvas.plain`）；吸附开关目前**只记状态与日志，未接线**。

## 四、2026-11-26 新能力现场验证

- [ ] 选中一个未声明 `type`、但脚本里有 `extend` 的方块：检查器类名显示推断类，并带「由脚本推断」徽标，类名只读。
- [ ] 选中一个既无 `type`、脚本也没有的方块：类名行显示警示徽标与「指定类」入口；填类名应用后变 `declared`，留空应用回到 `default`。
- [ ] F5 校验能看到 `scriptClass` 类 warning（同一记录不会与 `records` 规则重复报）。
- [ ] 预览页「导入贴图」选一张 PNG：缩略图立即更新，撤销一次文件恢复/删除，重做再写回。
- [ ] 关闭按钮、菜单「退出」、原生 X/Alt+F4 三条入口都先被壳拦下：dirty 时弹 `closeConfirm`，干净时直接关。
- [ ] 关窗对话框停留超过 3s 仍不自动关闭（前端已 `window_close_hold`）；取消后窗口保持打开。
- [ ] 断开后端制造命令错误时，右下角出现「操作失败」toast，3 秒内同一命令同一错误不重复弹。

## 五、文档与分层

- [ ] `src/` 未出现领域词，也未新增跨界通道；`REQ_KEY = 'requi' + 'rements'` 是分层扫描下唯一的数据字段拼接，改它前先读 [[前端分层守卫]]。
