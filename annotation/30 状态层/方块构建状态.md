# 方块构建状态

画布状态集中在 `S.board`，由 `board_snapshot` 一次物化。Rust 决定节点、卡片、连线与端口表，前端只做实测绘制与命中测试。

## 快照结构

`materializeBoard` 产出固定形状：

- `boards` 与 `board`：可用画板列表与当前画板。
- `nodes`：节点坐标与关联 contentId，逐项浅拷贝。
- `cards`：卡片描述，含 rows 与 inputFields，与 nodes 同序。
- `edges`：连线，reroutes 统一转成坐标对数组。
- `edgeStyle` 与 `viewport`：路由样式与视口。

`refreshBoard(boardIndex)` 在无项目时清空 board；有项目时取快照并同时刷新 `S.issues`。

## 交互写回

拖动、连线、中转点与删除都不在前端改数据，而是发壳命令并入撤销栈：

- `canvasMove` → `node_move_commit`。
- `canvasConnect` → `edge_connect`，端口字段来自拖拽起点。
- `canvasDisconnect` → `edge_disconnect`。
- `canvasInsertReroute` / `canvasMoveReroute` / `canvasRemoveReroute` 分别对应中转点增改删。
- `canvasDeleteNodes` → `record_delete`。

`canvasSelectNode` 对带 contentId 的卡片走统一 `select`，参照节点则清空选择。

> [!info] 几何常量共享
> 卡片尺寸、端口锚点与边路由数学全部来自 canvasGeometry.js，CanvasPane 只调用导出函数，不复制常量。

> [!warning] cards 与 nodes 必须同序
> 该顺序由 Rust 保证；前端按同一索引配对卡片与坐标，打乱会错位。

> [!tip] 新增端口规则时
> 规则应加在 Rust 快照与 canvasGeometry，而非在 CanvasPane 里临时判断。
