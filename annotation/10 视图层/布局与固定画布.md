# 布局与自适应

应用占满窗口，**1280×720 是设计基准，不再是固定画布**（2026-11-21 起）。窗口最小 960×600、默认 1200×650（由 Tauri 壳约束）；主区随窗口拉伸，资源网格按可用宽度自动增减列，侧栏与检查器宽度可拖动并持久化。

> [!info] 为什么改
> 固定 1280×720 是为了与设计稿逐像素对齐而做的妥协。现在按正常 Web 界面处理：小窗口内部滚动、大窗口利用空间，不做整体缩放变形。

> **2026-11-26 就地更正**：下表原文为 32/32/48/24，z1 重做样式层后高度全部来自 `tokens.css`：
> `--h-titlebar: 36`、`--h-toolbar: 44`（`min-height`）、`--h-tabs: 38`、`--h-status: 26`。
> 依据：`src/styles/tokens.css`、`views/home.css`、`components/layout/menubar.css`。

## 高度分配

| 区域 | 类名 | 高度 |
| --- | --- | --- |
| 标题栏 + 菜单栏 | `titlebar` | `--h-titlebar` = 36 |
| 工具栏（命令条） | `toolbar` | `--h-toolbar` = 44，`min-height`，窄窗可换行增高 |
| 页签条 | `workspace-tabs` | `--h-tabs` = 38 |
| 主区 | `workspace-area` | `flex: 1`，`min-height: 0` |
| 状态栏 | `statusbar` | `--h-status` = 26 |

主区内部滚动，不再依赖 584px 的固定高度；日志抽屉仍绝对定位在状态栏之上。

## 宽度分配

- assets：左栏由 `usePanelWidth` 管理（默认 232，可拖 180–380，存 `graphite.assetsSidebarWidth`）；检查器默认 328（可拖 280–560，存 `graphite.inspectorWidth`）；中间网格 `flex: 1`，`repeat(auto-fill, minmax(104px, 1fr))`，行高 104。
- units：同 assets 的两栏结构，左栏默认 232（`graphite.unitsSidebarWidth`）。
- tech：节点栏与编辑栏仍用 `clamp()`；中间画布 `flex: 1`。
- cosmos：行星树 `clamp()`；字段列 `clamp(280px, 30vw, 400px)`；预览区 `flex: 1`。
- canvas：整块画布占满主区，坐标计算基于 `getBoundingClientRect()`，窗口变化后自动适配。

## 窄窗行为

- 工具栏 `min-height: 44` 且允许换行，不出现横向裁切。
- 状态栏路径在宽度不足时隐藏，避免挤压计数与保存状态。
- 资源页左栏与网格各自纵向滚动；页面本身不出现横向滚动条。
- 四边热区由 `WindowResizer` 负责缩放（无框窗口），标题栏 `data-tauri-drag-region` 负责拖动。
- `Ctrl+\` 切极简模式（`S.ui.minimal`），隐藏非必要外框，给画布更多空间。

## 验证尺寸

- 960×600（最小窗口）：左栏、网格、检查器完整可见，无横向滚动。
- 1200×650（默认）：网格按 104px 最小宽自动排列（不再保证「六列」）。
- 1600×900：网格自动增列并拉伸卡片，检查器保持可拖动的上界。

> [!tip] 改布局的顺序
> 先改对应 CSS 末尾的“流体布局”段，再用 960/1200/1600 三档截图核对；不要把固定宽度加回去。

## 桌面交互（2026-11-21）

- 全局 `user-select: none`、`cursor: default`；只有 `input`、`textarea`、`select`、日志抽屉和 `.selectable` 允许选中，避免拖拽时选中文字。
- 右键菜单只在可编辑区域内保留；画布/科技树用右键平移，不弹浏览器菜单。
- 拦截浏览器行为：`Ctrl+R`、`Ctrl+P`、`Ctrl+U`、`Ctrl+±/0`、`Ctrl+滚轮`、`Alt+←/→`、中键自动滚动、文件拖放导航。
- 滚动条改为深色细样式（`scrollbar-color` + `::-webkit-scrollbar`）。
- 验证：画布空白处拖拽只改变 `.cv-world` 的 `translate`，`window.getSelection()` 为空。

## GPU 与星球预览（2026-11-21）

- WebView2 默认启动参数改为 **仅 `--no-sandbox`**；实测 ANGLE 使用 NVIDIA D3D11，Canvas 2D 回到硬件光栅。移除 `--disable-gpu` 后 1600×900 全质量拖拽 p95≈7ms。
- 若未来 WebView2 GPU 进程再次崩溃，可手工设置 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--no-sandbox --disable-gpu` 兜底。
- `CosmosPreview` 启动时探测 WebGL renderer：软件光栅才启用 640×480/拖拽 320×240 的 LOD 与大网格跳过描边；GPU 下保持全分辨率。
- 云层 120ms 定时重绘在拖拽期间统一暂停，避免周期性长帧。
