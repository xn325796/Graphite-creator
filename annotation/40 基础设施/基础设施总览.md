# 基础设施总览

基础设施指与业务无关、被状态层与面板共同依赖的底座：主体在 src/lib，另含 store 中承担文案与错误文本的两个模块。它不持有项目数据，只提供通道、提示、几何与文案。

## 组成

- [[IPC 桥接]]：ipc.js 的前端唯一跨界通道，封装 invoke 与 listen。
- [[Toast 与日志]]：toast.js 的即时轻提示，与 store 的日志抽屉分工。
- [[画布几何 canvasGeometry]]：卡片尺寸、端口锚点与三种边路由。
- [[国际化 messages]]：中文/英文两列文案表与 tr 取词。

store/validate.js 的 issueText 也属于这一层：它只负责把错误文本交给界面，校验规则本身仍在 Rust。

## 依赖边界

前端依赖面只有 vue 与 @tauri-apps/api。禁止引入 @tauri-apps/plugin-*、pinia、vue-router、vitest；跨界只允许 invoke/listen，禁止 fetch、XMLHttpRequest、WebSocket。

> [!info] 单一通道
> 所有与壳的交互都从 ipc.js 出发，状态层在其上包一层 call()，面板不直接引用 @tauri-apps/api。

> [!warning] 分层守卫会扫描
> src 全树受 layering 检查：额外依赖、领域词与额外网络通道都会直接判红。

> [!tip] 新增底座能力
> 先判断能否落在 lib 的既有模块；只有跨面板共享且与业务无关的能力才配进入这一层。
